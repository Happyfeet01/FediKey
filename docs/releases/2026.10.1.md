# FediKey auf Basis von Misskey 2026.10.1

Dieser Stand aktualisiert die Misskey-Basis von 2026.9.1 auf 2026.10.1 und erhält FediKeys Notizbearbeitung, History, ActivityPub-Updates, Argon2id-Anmeldung und verbesserte Nutzersuche.

## Enthalten

- Sicherheits- und Fehlerkorrekturen der Releases 2026.10.0 und 2026.10.1.
- Follow-Anfragen abhängig vom Accountalter; getrennt für lokale und entfernte Konten konfigurierbar unter Einstellungen → Datenschutz.
- Clip-Spalten im Deck und Entfernen von Avatar/Banner; sensible Bilder können nicht als Profilbilder ausgewählt werden.
- Automatische Archivierung von Ankündigungen zu einem einstellbaren Zeitpunkt.
- Verbesserte Moderation, Chat-Blockierungen, Accountmigration, Streaming und Push-Abonnements.
- Node.js 26.12.1 im Docker-Image, pnpm 12.14.0, Sentry 11.8.0 und die übrigen Upstream-Paketupdates.
- Deutsche und englische Texte für Follow-Schutz, Clip-Auswahl, sensible Profilmedien und automatische Ankündigungsarchivierung.

## Vor dem Upgrade

Datenbank, lokale Dateien und Konfiguration sichern. Das Upgrade zuerst in der Testinstanz prüfen. Bei einer Installation aus Quellcode wird pnpm 12.14.0 benötigt; das Dockerfile installiert die im `package.json` festgelegte Version automatisch. Unterstützte Node-Mindestversionen: 22.23.4 / 24.22.1 / 26.12.1.

Die neue Archivierungs-Migration ergänzt eine nullable Spalte `announcement.autoArchiveAt`. Bestehende Ankündigungen werden ohne gesetzten Zeitpunkt nicht automatisch archiviert. Eine weitere Upstream-Migration korrigiert ausschließlich den Kommentar zum Passwortfeld; vorhandene Passwort-Hashes werden nicht umgeschrieben. Die aus PR #12 bekannte Follow-Schutz-Migration bleibt ebenfalls enthalten.

## Sentry 11

Nur relevant, wenn Sentry verwendet wird:

- `sendDefaultPii` wird von Sentry 11 nicht mehr unterstützt. Misskey meldet dafür beim Start eine Warnung.
- Ohne explizite `dataCollection`-Konfiguration gelten Misskeys datensparsame Vorgaben: unter anderem keine Benutzerinformationen, Cookies, URL-Query-Parameter, HTTP-Bodys oder DB-Query-Werte.
- Eine explizite `dataCollection`-Konfiguration ersetzt diese Vorgaben. Insbesondere `dataCollection: {}` stellt Sentrys umfassendere Standarderfassung wieder her; dies nicht ungeprüft übernehmen.
- `profilesSampleRate` wird nicht mehr unterstützt; Backend-Profiling weiterhin über `sentryForBackend.enableNodeProfiling` konfigurieren.
- Die aktualisierten Beispiele befinden sich unter `.config/example.yml` und `.config/docker_example.yml`.

## Upgrade und Praxistest

Nach Freigabe den gewünschten FediKey-Stand auschecken und im Instanzverzeichnis neu bauen:

```bash
docker compose up -d --build web
docker compose logs -f web
```

Der Webstart führt ausstehende Datenbankmigrationen aus. Anschließend Anmeldung (einschließlich vorhandener Argon2id-Konten), Uploads, Notizbearbeitung/History, Federation, Follow-Schutz, Clip-Spalten, Push-Benachrichtigungen, geplante Archivierung und einen Neustart prüfen. Die Anwendung zeigt nun 2026.10.1 als Misskey-Basis an.

Eine Rückkehr zu einem älteren Image allein macht Datenbankmigrationen nicht rückgängig. Für eine vollständige Rückkehr den gesicherten Zustand wiederherstellen.
